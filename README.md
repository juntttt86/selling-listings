# selling-listings

위탁판매 상품 등록용 **공개 자산 레포**. 스피드고 자동화 플러그인
(Selling Master)이 이 레포를 읽어서 도매매 스피드고 전송을 준비한다.

**이 레포에는 민감 정보를 넣지 않는다** — 마진 계산, 계정 이력,
공급사 계약, 전략 문서 등은 전부 비공개 레포(`juntttt86/selling`)에만
있다. 여기 있는 건 등록에 실제로 쓰이는 상품명·이미지·배송정보 등
어차피 공개될 내용뿐이다.

## 구조

```
index.yml                        ← 도매매상품번호 → 폴더 경로 매핑
products/
  <상품 폴더명>/
    listing.yml                  ← 단일 진실 소스 (스키마는 agentbrief.md B절)
    images/                      ← listing.yml이 상대경로로 참조하는 이미지
```
